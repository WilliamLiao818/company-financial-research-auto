# AI-assisted development disclosure

Codex assisted with architecture, code generation, debugging, tests, interface copy and documentation. A human operator remains responsible for defining the research question, reviewing source data, choosing assumptions and interpreting outputs.

The calculations are deterministic and covered by tests; no language model is allowed to invent numeric values. The frozen dataset contains only normalized public SEC facts and source links. The application does not accept private files or personal data. Users must still verify source facts, challenge assumptions and review every material formula and limitation. The repository does not claim a completed valuation or an investment decision.
